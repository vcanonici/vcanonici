# Hi, I'm Vinicius.

I build practical software across AI, data, and systems. I like understanding how things work, finding what broke, and getting them working again.

Below are two completed projects you can explore: an interactive neural network and a documented hardware recovery.

### Interactive digit classifier

Draw a digit or load an image, then inspect the prediction, activations, and connections of the neural network. A model trained with PyTorch runs directly in your browser; your images stay on your device.

[Try the demo](https://vcanonici.github.io/Image-classifier-demo/) · [Explore the code](https://github.com/vcanonici/Image-classifier-demo)

### iPad mini 4 recovery lab

A recovery investigation that ended with an owner-confirmed normal boot. The repository brings together the timeline, technical findings, selected evidence, and Python tools for inspecting IMG4 structures and nonce consistency.

This is a documented result for one device, with the limits of the investigation stated explicitly.

[Read the case study](https://github.com/vcanonici/ipad-mini-4-recovery-lab/blob/main/docs/CASE-STUDY.md) · [Explore the tools and evidence](https://github.com/vcanonici/ipad-mini-4-recovery-lab)
